The folder contains 3 data files based on Colon data in Alon et al. 
(1999). The original data is for 2000 genes on 62 samples, and is 
available from 
http://microarray.princeton.edu/oncology/affydata/index.html. The 
following data files is the pre-processing version based on Dettling's 
paper, but it is of the same size. 

The 3 files are:

colon.rda, downloaded from http://stat.ethz.ch/~dettling/bagboost.html.
colon.x.txt, data matrix (2000 by 62) ready for use in Matlab.
colon.y.txt, vector of class index (62 by 1).

Related papers: Dettling Bioinformatics (2004), Alon et al. PNAS
(1999).
